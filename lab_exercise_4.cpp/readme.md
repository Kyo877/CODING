## 📂 Repository Structure

This project contains several C++ exercises, progressing from basic debugging to building small calculator programs. You can explore the folders below:

### 🛠️ Part A: Fundamentals & Debugging
* **`A1_syntax_error`** — Fixing basic C++ syntax errors.
* **`A2 - operator precedence`** — Understanding operator precedence and integer division quirks.

### 🧮 Part B: Coding & Logic
* **`B1_coding_rectangle_area_perimeter`** — Calculating the area and perimeter of a rectangle.
* **`B2_incometax`** — A simple income tax calculation program.
* **`B3_seconds into hours_minutes_seconds`** — Logic for converting total seconds into standard time format.
* **`B4_sizeof and limits`** — Exploring C++ data types and their memory limits.
* **`B5_type_conversion`** — Handling data type conversions safely in C++.

### 🎯 Part C: Further Practice
* **`C1_circle_calculator`** — Math calculations involving circles (radius, diameter, area).
* **`C2_readnumber_printback`** — Basic Input/Output (I/O) operations.

## 💻 How to Run in VS Code

To run any of these exercises locally using **Visual Studio Code**:

1. Clone this repository to your local machine and open the folder in VS Code.
2. Ensure you have a C++ compiler installed (e.g., `MinGW` for Windows or `clang` for macOS) and the **C/C++ Extension** by Microsoft enabled.
3. Open any `.cpp` file you want to test.
4. Click the **Run (Play)** button in the top right corner, OR use the terminal:

```bash
# Compile the code
g++ filename.cpp -o output_name

# Run the compiled program (Windows)
.\output_name.exe

# Run the compiled program (Mac/Linux)
./output_name
```
